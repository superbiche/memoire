# Vocabulary (binding)

> Moved from `README.md` 2026-07-25 under memoire:D173, verbatim: the README
> became pointer-only, and this block is binding law rather than a pointer.
> This document is the binding vocabulary of record. `docs/DERIVATION.md` is
> sealed as the v1 implementation brief and is not the home for it.

- **proposed / accepted / lapsed** — review states; `~` marks unreviewed (proposed or lapsed). Ignoring the
  review queue is a supported lifestyle.
- **elevate / demote** — the `can_instruct` gate; operator-pull only.
  Elevation is a standing-order subscription ("constrain every session in
  this project, regardless of subject"), NOT a truth tier — confirm is the
  trust apex for knowledge that should be found, cited, and believed but
  not injected. Elevate subject-independent constraints (caveats, gotchas,
  invariants); an important fact is confirmed, not elevated (memoire:D191).
- **benched** — an elevated observation beyond the injection cap: still
  confirmed, still `can_instruct`, but not riding sessions because the
  standing brief is full (the newest cap rides). Not a review state and
  not a demotion — a derived position, not a stored one; visible in the
  Browse elevated view and the injector's OVERFLOW header. The exit is an
  operator gesture: review and demote until the brief fits (memoire:D194).
- **kinds** (sealed): decision, preference, constraint, task, fact,
  open_question, gotcha.
- Event custody is total; taste is applied at derivation and injection, never
  by deleting capture.
